Outlook Email Assistant Support

This page provides support information for Outlook Email Assistant, a human-in-the-loop assistant for reviewing and organizing Outlook and Live.com email.

Common issues

Unable to connect a mailbox

Confirm that you are signing in with the intended Microsoft account and that you approve the requested authentication permissions.

Mailbox information is unavailable

The Microsoft connection may have expired or been revoked. Reconnect the account and try again.

Message cleanup

Outlook Email Assistant requires explicit user approval before moving a message to Deleted Items. It does not permanently delete messages, empty Deleted Items, or send email.
